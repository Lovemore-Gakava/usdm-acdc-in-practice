# Useful Resources

### Ecosystem References Mapped by Architectural Layer

1. **Library of Protocols Mapped to USDM** *(Layer 1: Protocol Digitization)*  
   [Protocol Explorer](https://protocolexplorer.io/) — Public library of protocols digitized into USDM.

2. **CDISC Analysis Concepts** *(Layer 3 & 4: AC/DC Pipeline & Execution Engine)*  
   [GitHub - cdisc-org/analysis-concepts](https://github.com/cdisc-org/analysis-concepts) — Core framework for Observation/Derivation/Analysis Concepts, eSAP, and WebR execution.

3. **USDM and M11 Resources** *(Layer 1: Protocol Digitization)*  
   [GitHub - data4knowledge/usdm_m11_resources](https://github.com/data4knowledge/usdm_m11_resources) — M11 protocol template to USDM attribute mapping dictionary.

4. **CDISC Biomedical Concepts (COSMoS)** *(Layer 2: Semantic Foundation)*  
   [GitHub - cdisc-org/COSMoS](https://github.com/cdisc-org/COSMoS) — Core ontology defining Biomedical Concepts (BCs) and observation variables.

5. **D4K USDM Workbench** *(Layer 1: Protocol Digitization)*  
   [GitHub - data4knowledge/study_definitions_workbench](https://github.com/data4knowledge/study_definitions_workbench) — USDM study definition authoring and validation workbench.

6. **Appsilon Mediforce Skills** *(Layer 5: AI Agent Orchestration)*  
   [mediforce/skills at main](https://github.com/Appsilon/mediforce/tree/main/skills) — Reusable AI agent skills for clinical data engineering.

7. **Atorus CDISC Pilot Replication** *(Layer 4: Execution & Audit)*  
   [GitHub - atorus-research/CDISC_pilot_replication](https://github.com/atorus-research/CDISC_pilot_replication) — R-based replication of CDISC pilot used as benchmark control (`ADAS-Cog`).

8. **R Consortium Pharma Skills** *(Layer 5: AI Agent Orchestration)*  
   [GitHub - RConsortium/pharma-skills](https://github.com/RConsortium/pharma-skills) — Biostatistical LLM skills and prompt templates.

9. **Kerfors Repositories**

   - **[cdisc-for-ai](https://github.com/kerfors/cdisc-for-ai)** *(Layer 5)* — Machine-actionable CDISC standards for LLMs and AI agents.
   - **[usdm-rdf](https://github.com/kerfors/usdm-rdf)** *(Layer 1)* — Turtle (RDF/OWL) rendering of CDISC USDM v4 for SPARQL queries.
   - **[soa2usdm](https://github.com/kerfors/soa2usdm)** *(Layer 1)* — Pipeline for parsing narrative Schedule of Activities (SoA) into USDM JSON.

10. **Biomedical Concepts to Synthetic Data** *(Layer 2: Semantic Foundation)*  
    [bc-supporting-synthetic-data](https://github.com/pendingintent/bc-supporting-synthetic-data) — BC-aligned synthetic clinical data generator.
