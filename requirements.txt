# Dependencies for the tools that read TORIVA's data.
#
# Needed by: tools/check_alignment.py (P3's data layer), tools/walkthrough.py
# (the .xpt conversion step 8 needs), tools/check_baseline_ambiguity.py.
# The tools that only read this repository's own documents need none of these
# and run on the system Python.
#
# Install with tools/bootstrap.py, which builds .venv with a 3.10+ interpreter.
# The floor is 3.10 because pyreadstat requires it; the repository's own code
# runs on 3.9.
#
# Lower bounds, not exact pins: this is a reference repository that should still
# install years from now, and the numbers it produces come from the data and the
# R engine, not from these packages' versions. The versions verified on
# 2026-09-26 (macOS, Python 3.13.13) are noted beside each.
