# Dependencies for the tools that read TORIVA's data.
#
# Needed by: tools/check_alignment.py (P3's data layer), tools/walkthrough.py
# (the .xpt conversion step 8 needs), tools/check_baseline_ambiguity.py.
# The tools that only read this repository's own documents need none of these
# and run on the system Python.
#
# Install with tools/bootstrap.py, which builds .venv with a 3.10+ interpreter,
# using the standard library's venv and pip and nothing else.
#
# uv was considered on 2026-09-26 and declined (LG). Measured on this dependency
# set: a first install on a new machine is 5.10 s with uv against 4.62 s with pip
# — the wheel download dominates — so it buys nothing for portability, which is a
# first-run-on-a-new-machine problem. Its 94x (0.05 s against 4.72 s) is on warm
# repeat installs, which is iteration comfort. Against that it would make uv a
# required tool to install before the bootstrap can run, which is the class of
# problem the bootstrap exists to remove.
# The floor is 3.10 because pyreadstat requires it; the repository's own code
# runs on 3.9.
#
# Lower bounds, not exact pins: this is a reference repository that should still
# install years from now, and the numbers it produces come from the data and the
# R engine, not from these packages' versions. The versions verified on
# 2026-09-26 (macOS, Python 3.13.13) are noted beside each.

pyarrow>=14.0        # verified 25.0.1 — parquet. NB pyarrow.dataset is blocked by
                     # Application Control on LG's Windows machine: use
                     # pq.ParquetFile(...).read(), not pq.read_table (CLAUDE.md)
pandas>=2.0          # verified 3.0.6
pyreadstat>=1.2      # verified 1.3.6 — write_xport, for step 8's .xpt
